 O objetivo deste site é mostrar e concientizar as pessoas, a ter uma visão melhor do cuidado com a natureza, dimunuindo o despedício nas colheitas, ultilizando menos água e preservando a natureza de forma susteável. Minha justificativa para escolher esse tema é mostrar que podemos produzir no agronegócio de forma sustentável, preservando o solo, cuidando da natureza e utilizando a tecnologia para garantirmos um futuro melhor, para as próximas gerações.
